# 📖 About

The **ABES SGPA & CGPA Calculator** is a web application designed specifically for **ABES Engineering College (AKTU)** students.

It allows students to calculate:

- 🎯 Semester 2 SGPA
- 📊 Overall CGPA
- 📚 Grade Points
- ⚡ Instant Results

The calculator follows the official ABES/AKTU grading system and automatically calculates SGPA and CGPA based on subject credits.
